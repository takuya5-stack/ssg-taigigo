# 対義語マスター（国語科B 第2学年）

学校プリント「類義語・対義語・多義語 演習問題」問1〜問3の対義語 全42語を、4択で練習できる1ファイルWebアプリ。

- 公開URL: https://takuya5-stack.github.io/ssg-taigigo/
- 出題形式: 熟語→対義語 / 対義語→熟語 / カタカナ→漢字 / ミックス
- 10問ごとのセッション、まちがえた問題だけの再挑戦、苦手だけ特訓
- 成績は各自の端末（localStorage）に保存。サーバーには何も送信しません。

更新するときは `index.html` を差し替えて commit & push。
